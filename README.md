# Sales Performance Analysis

## Project Overview

This project analyzes 5,000 sales orders from 2025 using SQL and Excel. The goal is to evaluate sales performance, profitability, regional results, and monthly sales trends.

## Tools

SQL  
Microsoft Excel  
Pivot Tables  
Pivot Charts  
Slicers

## Key Metrics

Total Sales: €1,224,815  
Total Profit: €824,168  
Total Orders: 5,000  
Profit Margin: 67%  
Average Order Value: €244.96

## Analysis

The project includes:

Sales by Region  
Sales by Category  
Profit by Region  
Profit by Category  
Monthly Sales Analysis  
Interactive Region Filtering

## Regional Sales

East: €235,443  
North: €251,475  
South: €378,039  
West: €359,858

South recorded the highest total sales among the four regions.
